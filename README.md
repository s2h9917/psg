# 📈 AI 펀더멘털 & 뉴스 감성 종목 추천기 (국내 · 실시간)

코스피·코스닥을 **네이버·야후 실시간 데이터**로 분석해 오늘의 추천 종목과 매수가·목표가·추천 사유를 도출하고, 추천 내역과 수익률을 관리하는 Streamlit 웹앱입니다. **KRX 직접 로그인이 필요 없습니다.**

## 구성
- `app.py` — Streamlit UI
- `engine.py` — 데이터 수집 + 스코어링 엔진
- `requirements.txt` — 의존성

## 데이터 소스 (KRX 로그인 불필요)
| 항목 | 소스 | 방식 |
|---|---|---|
| 코스피·코스닥 전종목 시세·시총·등락률 | 네이버/KRX 스냅샷 (FinanceData 팀의 GitHub 캐시) | 1회 다운로드 |
| 개별 종목 PER·PBR·ROE·배당 | 야후 파이낸스 (yfinance) | 정밀분석 후보에만 개별 조회 |
| 52주 고저·이평·모멘텀 | 야후 파이낸스 (yfinance) | 후보 주가 이력에서 계산 |

전종목은 GitHub 캐시에서 한 번에 받고, 시가총액 상위로 유니버스를 좁힌 뒤 **정밀분석 후보(기본 20종목)에 대해서만** 야후에서 개별 재무를 조회합니다. 코스피·코스닥을 함께 선택하면 후보가 시장별로 균형 있게 배분됩니다.

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
실행하면 브라우저(http://localhost:8501)에서 열립니다. 실시간 첫 실행은 야후 개별 조회로 30초~1분가량 걸릴 수 있습니다(이후 캐시로 빨라짐).

## 무료 웹 배포 (브라우저만으로, 터미널 불필요)
Streamlit Community Cloud에 올리면 `○○○.streamlit.app` 주소가 생깁니다.

1. **github.com** 가입 → **New repository**(Public) 생성.
2. 저장소에서 **Add file → Upload files** → `app.py`, `engine.py`, `requirements.txt` 세 파일 업로드 → **Commit**.
3. **share.streamlit.io** 접속 → **GitHub으로 로그인**(이메일로 계정 자동 생성).
4. 우측 상단 **Create app** → 방금 만든 저장소·브랜치(main)·파일(`app.py`) 지정 → 원하는 subdomain 입력.
5. **Deploy** → 몇 분 뒤 배포 완료. 생성된 `https://내앱이름.streamlit.app` 주소로 어디서든 접속.

## 참고 / 한계
- 일부 종목은 야후에 재무(PER/PBR/ROE)가 없어 **중립값**으로 처리될 수 있습니다.
- 야후 개별 조회는 종목당 1~2초가 걸리므로 '정밀분석 후보 수'를 늘리면 느려집니다.
- 추천 내역은 `recommendation_history.csv`에 저장됩니다. 로컬은 영구 보존되지만 **클라우드(Community Cloud)는 재배포·휴면 시 초기화**되므로, 클라우드에서 영구 보존하려면 Google Sheets/DB 연동이 필요합니다.
- (선택) 사이드바에 네이버 뉴스 검색 API 키를 넣으면 심리 지표가 실제 뉴스 헤드라인 감성으로 대체됩니다.

## 스코어링 요약
- 정밀분석 후보 내 **백분위(percentile) 랭킹**으로 각 지표를 0~1로 정규화 → 이상치에 강건.
- 종합점수 = 펀더멘털(ROE·PER·PBR·배당) × w1 + 시장심리(모멘텀/뉴스) × w2 + 상승여력 × w3 (가중치 사이드바 조절, 자동 정규화).
- 매수가: 20일선·현재가 눌림목 / 목표가: 52주 고점·점수 차등 상승률 / 손절가: 60일 저점 기준.

## ⚠️ 유의사항
본 앱은 투자 참고용 도구이며 투자 자문·매매 권유가 아닙니다. 매수가·목표가·손절가는 기술적·밸류에이션 참고 기준일 뿐 미래 수익을 보장하지 않으며, 모든 투자 판단과 책임은 투자자 본인에게 있습니다.
